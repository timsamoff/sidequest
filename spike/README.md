# Drive sync spike

A throwaway test page for Sidequest's planned Google Drive sync. It contains no Sidequest code or data and is not part of the app. Kept as a record only.

Drive sync was dropped on 2026-11-21 in favor of sync on Cloudflare. The spike's deployment was removed the same day, and the OAuth client and API key in `drive-sync-spike.html` are being retired, so the page no longer signs in.
